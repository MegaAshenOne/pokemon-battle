
# Pokemon Battle V1

A simple turn-based battle game developed in Python as a programming learning project.

## Features

- Turn-based combat between player and enemy.
- Attack system with damage calculation.
- Paralysis mechanic with a chance to lose a turn.
- Healing system with limited uses.
- HP management with a maximum value of 100.
- Random enemy actions.

## Technologies

- Python 3
- Random module
- Dictionaries
- Functions
- Conditional statements
- While loops

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run:

```bash
python pokemon_battle.py
```

## Project Goal

This project was created to practice programming logic, Python fundamentals, functions, dictionaries, loops and state management.

More features and improvements will be added in future versions.
